# RAG 与 Agent 应用：可能的面试问题

## RAG

- 一次问答从文档入库到回答生成经历哪些步骤？每一步可能丢失什么信息？
- 文档怎样切块？块大小、重叠与标题结构如何影响检索？
- 向量检索、关键词检索、混合检索与重排分别解决什么问题？
- 检索不到、检索错了与回答编造如何区分？怎样通过日志和样本定位？
- 用户追问时怎样改写查询并保留上下文？如何限制重试次数？
- 如何设计评测集？检索质量、回答正确性、引用质量、时延和成本怎样分别衡量？
- 如何处理权限过滤、文档更新、重复文档和过期知识？
- 资料不足时如何拒答？怎样验证引用确实支持回答中的结论？

## Agent 与工具调用

- 哪些步骤需要模型判断，哪些步骤应由确定性代码完成？
- Function Calling、Skill 与 MCP 在项目中各承担什么作用？
- 工具参数如何校验？用户身份和数据权限由哪一层保障？
- Text-to-SQL 怎样防止越权查询、危险 SQL 与业务口径错误？
- 模型生成 SQL 可以运行，为什么仍可能查错数据？怎样验收？
- 工具超时、失败、重试和取消如何处理？如何避免重复产生业务副作用？
- 多步任务如何记录状态并恢复？怎样防止无限循环和费用失控？
- 图表、Excel 与回答中的数字如何保持一致？
- 如何防范文档或工具返回内容中的提示注入？

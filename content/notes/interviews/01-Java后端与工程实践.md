# Java 后端与工程实践：可能的面试问题

## 并发与排障

- 线程池的核心线程数、队列和拒绝策略如何选择？请求突然增加时会发生什么？
- 如何定位 CPU 飙高、死锁、内存泄漏与频繁 GC？会先收集什么证据？
- synchronized、Lock 和 CAS 分别适用于什么场景？怎样解释可见性与原子性？
- CompletableFuture 的异常、超时和线程池如何管理？阻塞任务会产生什么影响？
- 重试为什么可能导致重复执行？幂等键如何设计，失败后如何恢复？

## 数据库与业务一致性

- 事务隔离级别如何影响业务？如何处理并发修改同一笔预算或费用？
- 慢 SQL 如何排查？索引失效、执行计划与数据分布之间有什么关系？
- 查询结果正确但业务口径错误时，怎样查清过滤、聚合和权限条件？
- Oracle 迁移 PostgreSQL 时，要核对哪些 SQL、类型、空值与事务语义？
- 数据库切换如何灰度、核对数据并回退？切换后新增数据怎样处理？

## 升级与方案设计

- JDK 8 升级 JDK 21 的兼容风险如何识别？依赖、构建与运行环境怎么核对？
- 虚拟线程适合什么任务？怎样验证收益以及数据库连接池等下游限制？
- 如何设计灰度指标、回退条件与回归范围？
- 报表导出的数据量很大时，怎样控制内存、分页、权限和任务超时？

# 面试问题索引与练习方法

这里集中保存 Java 后端转 AI 应用工程师时可能被问到的问题。问题用于练习，不代表已经完成对应项目或掌握全部能力；回答应以自己的实际经历、代码和实验为依据。

## 每道题的记录方式

1. 问题：面试官的原话与实际追问。
2. 我的回答：先用一两句话回答，再讲机制和取舍。
3. 证据：代码位置、测试、日志或可复现的实验；设计方案要明确标注。
4. 不足：哪里讲不清楚，哪里还没有实现或验证。
5. 下一步：补充资料、复现实验，并记录复习日期。

练习时先做两分钟口述，再接受追问。面试后把新问题补到对应主题，优先处理反复出现的薄弱点。

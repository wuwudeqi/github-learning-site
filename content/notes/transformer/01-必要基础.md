# 第 01 章：参数、预测与训练

## 本章目标与节奏

读完后，你应该能解释“模型”“参数”“预测”“损失”“训练”，并手算一次参数更新。上午读到“模型怎样调整参数”，下午完成手算、自测与选读；晚上可运行文末代码。

暂时不用记 Transformer 的模块名称。先理解所有后续实验都会用到的学习过程。

## 1. 模型是一个带有可调数字的计算规则

假设我们人为构造一组数据：输入 1，希望输出 2；输入 2，希望输出 4；输入 3，希望输出 6。这里的规律由我们设定，真实任务通常没有这样简单的规律。

我们先选一个模型：

```text
y_hat = w × x + b
```

x 是输入，y_hat 是预测，w 和 b 是可以调节的参数。先取 w = 1、b = 0，那么输入 2，预测就是 2。目标是 4，模型还没给出我们希望的结果。

**架构决定怎么算，参数决定当前算出什么。** 在这个例子里，架构是“先乘再加”，参数是乘多少、加多少。训练的主要任务是根据数据调整参数。

## 2. 向量和矩阵把计算组织起来

一个输入可以有多个特征。例如某个虚构任务的输入为 x = [2, 3]，参数为 w = [0.5, 1]，偏置为 b = 0.2。

```text
y_hat = 2 × 0.5 + 3 × 1 + 0.2 = 4.2
```

前两项是点积：对应位置相乘，再相加。点积用于许多场景，不能一概解释成语义相似度。

![两个样本组成输入矩阵，与参数矩阵相乘后得到预测列向量](images/matrix.svg)

图中每一行是一个样本，每一列是一个特征。矩阵乘法的形状规则是：

```text
X: (样本数, 输入特征数)
W: (输入特征数, 输出特征数)
X @ W: (样本数, 输出特征数)

本例：(2, 2) @ (2, 1) → (2, 1)
```

相邻的两个维度必须相等。加入偏置时，对每个样本的输出加上同一个 b，结果为 [4.2, 4.7] 的列向量。后续学习中，一个 Token 也会用一串数字表示，但这些数字通常不是人为标好的“词性”“情感”等属性。

## 3. 用损失衡量预测偏差

回到单个样本 x = 2、目标 y = 4、预测 y_hat = 2。定义一个教学用损失：

```text
L = (y_hat - y)² = (2 - 4)² = 4
```

平方保证损失非负，并让较大的误差受到更大惩罚。多个样本可以取平方误差的平均值，称为均方误差。这里不是让你记住所有损失函数，而是建立“用一个数评价当前预测”的认识。

语言模型预测下一个 Token 时通常使用交叉熵，后续会从概率讲起。本章的平方误差只服务于这个数值预测例子。

## 4. 模型怎样调整参数

![训练先计算预测与损失，再通过梯度和优化器更新参数；预测流程不包含参数更新](images/training.svg)

按图读一遍：输入经过模型得到预测；用目标计算损失；求损失对参数的梯度；优化器根据梯度更新参数；再开始下一次计算。

梯度描述参数发生很小变化时损失的变化趋势。它不是“正确答案”，也不是损失本身。最基础的梯度下降规则是：

```text
新参数 = 旧参数 - 学习率 × 梯度
```

学习率控制每次调整幅度。步子过大可能越过较好的位置，甚至使训练发散；一次更新也不保证适用于所有数据。

### 手算一次更新

仍使用 x = 2、y = 4、w = 1、b = 0，学习率取 0.1。对这个模型和损失，梯度为：

```text
误差 e = y_hat - y = -2
w 的梯度 = 2 × e × x = -8
b 的梯度 = 2 × e = -4

w_new = 1 - 0.1 × (-8) = 1.8
b_new = 0 - 0.1 × (-4) = 0.4
```

两个梯度都必须用更新前的参数计算，再一起更新。

用新参数预测相同样本：1.8 × 2 + 0.4 = 4，损失变为 0。但对 x = 3，预测是 5.8，并不等于目标 6。**把一个样本拟合正确，不代表学到了适用于其他输入的规律。**

## 5. 神经网络多了什么

刚才的模型只做线性变换加偏置。更复杂的网络会组合多个变换，并穿插非线性函数，例如 ReLU：负数变成 0，非负数保持原值。

```text
输入 → 线性变换 → ReLU → 线性变换 → 输出
```

如果中间完全没有非线性，不论堆多少个这样的线性层，它们都能合并成一个线性变换加偏置，表达能力不会因为层数增加而自动变强。

Transformer 也是带有可训练参数的神经网络。后面会介绍它如何让不同位置交换信息，以及为什么还需要逐位置的前馈网络。本章只需要把握：每个模块最终都在做可计算的变换，参数通过训练调整。

## 6. 训练与预测的区别

| 环节 | 训练 | 常规预测／推理 |
| --- | --- | --- |
| 输入 | 训练样本 | 待处理的输入 |
| 目标答案 | 用于计算训练损失 | 通常不提供 |
| 梯度与更新 | 计算梯度并调整参数 | 通常不计算梯度、不调整参数 |
| 目的 | 学习可泛化的规律 | 使用已学参数给出结果 |

评估时也可能计算损失，但不更新参数。看到损失不等于正在训练。

训练集用于调整参数，验证集帮助选择设置，测试集用于最终评估。只盯着训练损失，可能忽略过拟合：模型在见过的数据上表现好，在新数据上却表现差。

聊天时，把前文加入输入可以改变模型的回答；这与更新模型参数是两件不同的事。

## 7. 晚间可选实验：只用 Python

示例文件：[01_linear_learning.py](code/01_linear_learning.py)。不需要第三方库。在家中终端进入专题目录后运行：

```bash
python3 code/01_linear_learning.py
```

它先验证本章单样本手算，再对三个训练样本一起训练，打印损失和新输入的预测。代码直接写出这个简单模型的梯度；复杂模型的自动求导会在后续讲解。

先猜后运行：

1. 把学习率从 0.05 改为 0.005，同样更新 200 次，收敛会如何变化？
2. 把训练数据改成只有 (2, 4)，能否仅凭该样本确定唯一的 w、b？
3. 比较训练样本与 x = 4 的预测。这个人工例子的表现能否证明真实任务也能外推？

参考观察：更小的学习率通常在固定步数下进展较慢；单样本只约束 2w + b = 4，存在无穷多组解；合成线性数据不能证明真实任务的外推能力。

## 8. 自测：先遮住下面的答案

1. 公式 y_hat = w × x + b 中，哪些是参数，哪些是数据？
2. x = 3、w = 2、b = 1、y = 6，预测与平方误差分别是多少？
3. (4, 3) 的输入乘 (3, 2) 的权重，输出形状是什么？
4. 训练损失为 0，能否断定新数据表现良好？
5. 不更新参数时，换一个输入能否改变输出？
6. 为什么堆叠纯线性层不够？

### 参考答案

1. w、b 是参数；x 是输入数据，y 是目标数据，y_hat 是计算出的预测。
2. 预测为 7，平方误差为 1。
3. (4, 2)：四个样本，每个样本有两个输出特征。
4. 不能，必须观察独立数据；还需考虑数据泄漏及评估设计。
5. 可以。固定计算规则和参数，对不同输入本来就可能得到不同输出。
6. 多层仍可以合并成一个线性变换加偏置；需要非线性才能表达更丰富的关系。

## 9. 选读：梯度公式从哪里来

把计算拆成 w → y_hat → e → L。微小改变 w，会先改变预测，再改变误差，最后改变损失。链式法则把沿途的变化率相乘。

```text
L = e²，对 e 的变化率是 2e
e = y_hat - y，对 y_hat 的变化率是 1
y_hat = wx + b，对 w 的变化率是 x
所以 dL/dw = 2e × 1 × x

同理 dL/db = 2e × 1 × 1
```

当损失是 n 个样本的均值时，每个参数的梯度也取这些样本梯度的均值。后续反向传播会将这种链式计算推广到整个网络。

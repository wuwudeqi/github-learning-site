# 参数、预测与训练

语言模型会给下一个 Token 打分。这里先解决更基础的问题：**计算规则中的数字为什么能从例子中逐渐变得有用？**

直接拿文字做第一道训练题，会同时遇到分词、矩阵、概率和求导。我们先经营一家虚构打印店：看历史订单，学着估计新订单的费用。这个任务能用纸笔算完整；第 05 章再把费用换成候选 Token 的概率。

所有订单都是合成教学数据。我们关心的是计算，不是实际定价。

## 1. 模型是怎样的一条可调规则

历史订单如下：

| 页数 x | 实际费用 y |
| ---: | ---: |
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |

你能一眼看出“每页 2 元”。但程序暂时不知道这个答案。先选一种允许它调整的规则：

```text
预测费用 = 每页价格 × 页数 + 固定费用
  y_hat = w × x + b
```

x 是输入，y 是记录中的目标，y_hat 是当前预测；w、b 是所有订单共同使用的**参数**。暂时设 `w=1、b=0`，打印两页就预测 `1×2+0=2` 元，比目标 4 元少了 2 元。

这里有两种不同改变：

| 改变什么 | 计算 | 含义 |
| --- | --- | --- |
| 参数不变，页数从 2 换成 3 | 1×3+0=3 | 同一模型处理新输入 |
| 页数不变，把 w 调到 1.5 | 1.5×2+0=3 | 改变模型的参数 |

普通推理主要做第一类事；训练根据数据做第二类事。**模型结构规定允许怎样计算，参数决定当前具体算出什么。** 本例的结构只允许“乘后加”，训练不会自动把它改成一张任意收费表。

## 2. 算得好不好：为什么需要损失

比较两套参数，误差统一定义成“预测减目标”：

| 候选 | 三张订单的预测 | 三次误差 | 误差之和 |
| --- | --- | --- | ---: |
| A：w=1，b=0 | 1、2、3 | −1、−2、−3 | −6 |
| B：w=1，b=2 | 3、4、5 | +1、0、−1 | 0 |

B 的误差之和是 0，却仍有两张订单算错。直接相加会让多估与少估抵消。

先平方、再平均，就能避免抵消：

```text
L_A = [(-1)² + (-2)² + (-3)²] / 3 = 14/3 ≈ 4.666667
L_B = [(+1)² + 0² + (-1)²] / 3 = 2/3 ≈ 0.666667
```

L 叫损失。本章选的是均方误差，英文缩写 MSE。按这个标准，B 在这三张订单上更好。

为什么平方？除了消除正负，误差从 1 增加到 2 时，惩罚会从 1 增加到 4。为什么平均？避免仅仅因为订单变多，总损失就跟着增加。绝对误差等其他标准也可以使用，损失必须根据任务选择。

不过，`L=4` 只是一个评价。它还没有告诉我们 w、b 分别该向哪个方向改。这需要继续追踪参数怎样影响损失。

## 3. 不先背求导公式，也能看懂梯度

只看两页订单：`x=2、y=4`，从 `w=1、b=0` 出发。固定 b，试着把 w 改动一点：

| w | 预测 2w | 损失 (2w−4)² |
| ---: | ---: | ---: |
| 0.99 | 1.98 | 4.0804 |
| 1.00 | 2.00 | 4.0000 |
| 1.01 | 2.02 | 3.9204 |

w 增大 0.01，损失减少 0.0796。附近的变化率约为：

```text
(3.9204 - 4) / (1.01 - 1) = -7.96
```

试探幅度趋近于 0 时，这里的变化率趋近 −8。它叫损失对 w 的导数。多个参数各有一个这样的变化率，把它们放在一起，就是梯度。

负号表示“在当前位置附近，增加 w 会减少损失”，所以为了让损失下降，需要沿梯度的反方向更新。

### 3.1 把 −8 的来路拆成三段

画出真实的计算顺序：

```text
w → y_hat=wx+b → e=y_hat-y → L=e²
```

在 `x=2、e=-2` 的这个点：

1. w 每变化一点，预测以 x=2 倍的速率变化。
2. 减去固定目标 y，不改变这个变化率。
3. 平方函数在 e 处的变化率为 2e，此处是 −4。

沿途变化率相乘，得到：

```text
dL/dw = 2e × 1 × x = 2 × (-2) × 2 = -8
dL/db = 2e × 1 × 1 = 2 × (-2)     = -4
```

这就是链式法则。b 直接加到预测上，因此对应的那一段变化率是 1。`dL/dw` 读作“损失对 w 的变化率”；有多个参数时也写成 `∂L/∂w`，表示考察 w 的变化时固定其他参数。

复杂网络只是计算路径更多。**反向传播**沿这些路径传回梯度；遇到一项通过多条路径影响损失，要把各条路径的贡献相加。它并不是让网络倒着生成文字。

### 3.2 为什么不永远靠加一点、减一点试探

本例只有两个参数，可以试。若有大量参数，逐个试探需要许多次计算。反向传播利用计算图组织求导，能共同计算这些参数的梯度。

小幅试探仍很有用：它可以独立核对求导代码。[第 05 章](05-模型怎样从文本中学习.md)会把输出层的解析梯度与中心差分逐项比较。

## 4. 算完一次训练，再故意让它失败

### 4.1 同时更新两个参数

最基本的梯度下降规则是：

```text
新参数 = 旧参数 - 学习率 × 梯度
```

学习率控制步幅。取 0.1：

```text
旧参数：w=1，b=0
旧预测：1×2+0=2
目标：4
误差：-2
梯度：w 对应 -8，b 对应 -4

新 w = 1 - 0.1×(-8) = 1.8
新 b = 0 - 0.1×(-4) = 0.4

新预测：1.8×2+0.4=4
新损失：(4-4)²=0
```

两个梯度都站在**同一组旧参数**上计算，然后一起更新。不要先改 w，再用新 w 算 b 的梯度，否则执行的就不是这里这一次更新。

![从预测、损失到反向传播和参数更新的训练过程](images/training.svg)

前向计算负责算预测和损失，反向传播负责算梯度，优化器负责按规则更新。本例的优化器使用普通梯度下降。

### 4.2 梯度方向正确，步子也可能迈错

每行都重新从 `w=1、b=0` 出发，使用同一组梯度：

| 学习率 | 新 w | 新 b | 对两页的预测 | 新损失 |
| ---: | ---: | ---: | ---: | ---: |
| 0.01 | 1.08 | 0.04 | 2.2 | 3.24 |
| 0.10 | 1.80 | 0.40 | 4.0 | 0 |
| 0.30 | 3.40 | 1.20 | 8.0 | 16 |

原来的损失为 4。0.30 这一步越过了目标，反而更差；继续用 0.30 更新一次，预测会变成 −4，损失扩大到 64。

梯度描述当前位置附近的趋势，不能保证沿这个方向走多远都更好。0.1 在本题一步算对是数字恰好配合，不能直接照搬给另一个模型。

### 4.3 一张订单损失为 0，为什么还没学会规律

刚得到的 `w=1.8、b=0.4` 在其他页数上如何？

| 页数 | 目标 | 预测 |
| ---: | ---: | ---: |
| 1 | 2 | 2.2 |
| 2 | 4 | 4.0 |
| 3 | 6 | 5.8 |
| 4 | 8 | 7.6 |

一张订单只约束 `2w+b=4`。`w=2、b=0` 满足它，`w=1、b=2` 也满足，甚至 `w=0、b=4` 都满足。数据不足，无法确定唯一规则。

把多张订单一起训练，就是要求同一组参数同时照顾它们。若损失取 n 张订单的平均，梯度也取平均：

```text
gw = sum(2 × 每张订单的误差 × 该订单页数) / n
gb = sum(2 × 每张订单的误差) / n
```

这里相加的是“同一个参数在不同样本上的梯度贡献”，不是给每张订单永久分配一套自己的参数。

## 5. 从一张订单走到矩阵乘法

换一个独立场景：黑白每页 0.5 元、彩色每页 1 元，固定费用 0.2 元。订单有两种输入，就按固定顺序放进向量：

```text
x = [2, 3]       # 黑白 2 页，彩色 3 页
w = [0.5, 1]     # 对应的两种单价
预测 = 2×0.5 + 3×1 + 0.2 = 4.2
```

对应位置相乘再相加，叫点积。这里它计算费用；在注意力里，点积会承担匹配打分的任务。同一种算术，不必只有一种含义。

加入另一张“黑白 1 页、彩色 4 页”的订单，把输入按行排起来：

```text
     黑白  彩色
X = [ 2,    3 ]
    [ 1,    4 ]

W = [ 0.5 ]
    [ 1.0 ]

X @ W = [ 4.0 ]   加 b=0.2 → [ 4.2 ]
        [ 4.5 ]              [ 4.7 ]
```

`@` 是矩阵乘法。它一次组织了两次点积，没有另造一条收费规则。

![每行订单乘以对应单价，再加入固定费用](images/matrix.svg)

如果有 5 张订单，每张 3 个特征，要分别输出 2 个数，可以使用：

```text
X: (5, 3)   @   W: (3, 2)   →   输出: (5, 2)
```

W 的每一列负责一个输出。中间的 3 要一致，保证每个输入特征都找到对应权重；外侧的 5 和 2 决定结果形状。

后面的教材统一把一个 Token 的表示写成行向量。`X` 的行会变成“位置”，列会变成“特征”，不再是订单与页数。**先说清行列含义，再检查形状**，比只背乘法口诀可靠。

## 6. 多接几层乘法，为什么还不够

假设收费改成“前两页每页 2 元，超过两页的部分每页 1 元”：

| 页数 | 费用 |
| ---: | ---: |
| 1 | 2 |
| 2 | 4 |
| 3 | 5 |
| 4 | 6 |

单个 `wx+b` 的每页增量永远是 w，不能同时满足两种斜率。延长训练解决不了这种表达限制。

那就先算 `h=2x+1`，再算 `y_hat=3h+4` 呢？展开后得到 `6x+7`，仍是一条直线。一般地，只把线性变换和偏置连接起来，仍可合并成一个仿射变换。

加入一个简单的转折函数 ReLU：

```text
ReLU(z) = max(0, z)
费用 = 2x - ReLU(x-2)
```

| x | x−2 | ReLU(x−2) | 最终费用 |
| ---: | ---: | ---: | ---: |
| 1 | −1 | 0 | 2 |
| 2 | 0 | 0 | 4 |
| 3 | 1 | 1 | 5 |
| 4 | 2 | 2 | 6 |

前两页不减价，之后每页减 1 元，恰好产生需要的转折。这个公式是手工构造的，证明了“可以表达”，还没有证明某个训练程序已经自己学会它。

Transformer 的前馈网络也把可学习变换与非线性连接起来。注意力负责让位置之间交换信息，前馈网络再对每个位置的表示进行变换。[第 04 章](04-从网络层到生成循环.md)会把这两部分接成一整层。

## 7. 从旧订单接回语言模型

如果程序把三张历史订单背下来，遇到其他页数一律输出 0，它在旧订单上全对，在新订单上却很差。我们需要关心**泛化**：面对没有用于训练的输入，学到的规则是否仍然有效。

训练集用于更新参数；验证集帮助比较学习率等设置；测试集留作最终检查。若反复根据测试结果改方案，这部分数据就已经参与了选择，不能再当作完全独立的评价。

评估也可以计算损失，但不必更新参数。所以“有损失”不等于“正在训练”。换一家收费规则完全不同的店，又涉及输入或规律的变化，不能由这三张订单保证任意场景的结果。

把本章的对象替换成语言模型：

| 环节 | 打印任务 | 下一个 Token 预测 |
| --- | --- | --- |
| 输入 | 页数特征 | 前缀的向量表示 |
| 输出 | 一个费用数值 | 每个词表项的分数 |
| 目标 | 实际费用 | 后续 Token 的编号 |
| 本书采用的损失 | 均方误差 | 交叉熵 |
| 更新方式 | 求损失对 w、b 的梯度 | 求损失对网络参数的梯度 |

这里有一个不能照搬的地方：Token 编号只是类别标识。编号 4 比编号 2 大，不意味着预测 3 就“距离正确答案更近”。因此我们把它作为分类问题，评价分给目标类别的概率。[第 05 章](05-模型怎样从文本中学习.md)会实际算出 `-log(目标概率)` 及其梯度。

## 8. 运行、改条件，再解释变化

下载 [01_linear_learning.py](code/01_linear_learning.py)，运行 `python3 01_linear_learning.py`；如果位于仓库专题目录，则运行：

```bash
python3 code/01_linear_learning.py
```

程序先逐一复现第 2–6 节的数字，再用三张订单共同训练 200 次。下面是更新函数的核心，注意误差和梯度都在参数更新前计算：

```python
errors = [w*x + b - y for x, y in samples]
gw = sum(2*e*x for (x, _), e in zip(samples, errors)) / len(samples)
gb = sum(2*e for e in errors) / len(samples)
w, b = w - learning_rate*gw, b - learning_rate*gb
```

第一次运行，核对损失和学习率表。第二次只改文件末尾的一项：

| 改动 | 先预测 | 应该解释的结果 |
| --- | --- | --- |
| 学习率从 0.05 降到 0.005 | 相同 200 步会学得更快吗？ | 在这组初值和数据上，小步幅进展更慢；步子小不等于有限步数内更好 |
| 样本只留 `(2,4)` | 训练损失趋近 0 后，4 页一定为 8 吗？ | 不一定；一个方程不能确定两个参数 |
| 样本改成 `(1,2),(2,4),(3,5),(4,6)` | 一条直线能把它们全算对吗？ | 不能；这里首先受模型表达形式限制 |

固定案例的断言通过，只说明这些计算得到核对。你修改后的实验，应当重新看损失、逐条预测和未见输入，不要把一个“通过”当作所有问题已经解决。

## 9. 自测与解答

**题一：** `x=3、w=2、b=1、y=6`，预测、误差和平方损失各是多少？

**解答：** 预测 7，误差 1，损失 1。这里误差的正号表示多估。

**题二：** 两张订单分别多估 2 元、少估 2 元，均方误差为 0 吗？

**解答：** 为 `(2²+(-2)²)/2=4`。为 0 的是有符号误差的平均，二者评价不同。

**题三：** w 的梯度为 −8，学习率 0.01，旧 w=1，更新后是多少？如果写成 `w+学习率×梯度` 会怎样？

**解答：** 正确结果 `1.08`。写成加号会得到 `0.92`，在本题当前位置向损失上升的方向移动。

**题四：** `X` 有 7 行、每行 4 个特征，希望每行输出 6 个分数，W 形状是多少？

**解答：** `(4,6)`，输出为 `(7,6)`。第 04 章的语言模型输出层就是这种“表示宽度 → 词表大小”的映射。

**题五：** 为什么同时调整 w、b 时，不能改完 w 再重新计算 b 的梯度，并仍声称使用了原先那组梯度？

**解答：** 新 w 改变了预测和误差，b 的梯度也会随之变化。两个梯度此时来自不同参数点。那可以形成另一种更新过程，但不是本章手算的一步。

**题六：** 提示词从“续写”改成“翻译”，模型输出改变。这与打印任务的哪种变化更相似？

**解答：** 参数保持不变而输入变化。不能只从输出变化推断它训练了，也不能把对话中的“纠正一次”直接等同于梯度更新。

## 本章完成标准

离开正文，能用两页订单算出 `预测=2 → 损失=4 → 梯度=(-8,-4) → 新参数=(1.8,0.4)`，并解释为什么这仍不足以证明模型学会了收费规律。

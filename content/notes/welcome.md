# 从这里开始，认识森空间

> 这是森空间的示例文档，用来体验阅读、目录跳转和进度恢复。正式资料可以随时替换。

## 一处安静的阅读空间

森空间用来收纳论文、书籍和学习笔记。打开书架，找到想读的内容，接着上次的地方读下去。

你不需要注册，也不需要在公司上传文件。资料在家中整理好后发布，阅读记录则留在当前浏览器里。

## 找到一份资料

左侧可以按**论文、书籍、笔记**筛选。搜索框支持标题、作者、标签和 Markdown 正文搜索，PDF 暂时只搜索资料信息。

| 操作 | 方法 |
| --- | --- |
| 打开资料 | 点击标题或「开始阅读」 |
| 收藏资料 | 点击星形图标 |
| 下载原文件 | 点击下载图标 |
| 恢复进度 | 点击「继续阅读」 |

## 阅读 Markdown

文章支持标题、表格、引用、链接、配图和代码块。右侧目录会根据文章内容自动生成。

```javascript
const reading = {
  place: '森空间',
  rhythm: '按自己的节奏',
};
console.log(reading.place);
```

每段内容不必一次读完。页面滚动时会保存相对位置，下次进入这篇文章会恢复。请使用同一个浏览器和同一个网站地址。

## 阅读 PDF

PDF 阅读器支持翻页、页码跳转、缩放与文本选择。读到哪里，阅读器就记到哪里。首次打开大文件时，请耐心等待。

如果当前浏览器无法预览，可以使用右上角的下载按钮，把 PDF 下载后使用本机阅读器打开。本机阅读器的进度不会回传到本站。

## 关于本地记录

收藏、最近阅读和文章进度使用浏览器本地存储。关闭页面后通常仍会保留；换浏览器、使用无痕窗口或者清除网站数据，可能无法继续使用这些记录。

**它们不会自动同步到其他电脑。** 如果浏览器禁止本地存储，网站会给出提醒，你仍然可以阅读和下载资料。

## 添加自己的内容

在家里的项目目录中添加 Markdown 或 PDF，然后让 Codex 更新并发布即可。每份文档都有一个固定编号，不要因为改标题就修改编号，这样阅读记录仍能对应同一份资料。

Markdown 可以和图片放在同一文件夹，通过相对路径引用。站点会把这些文件一起发布，不依赖外部图片服务。

## 慢慢读，也是一种进步

你可以从每天的一小节开始。读完一篇，在阅读器里点「标记已读」；暂时没有读完的内容，会留在「最近阅读」里。

比起收集的数量，更重要的是你真正理解了什么。留下一点时间，把刚才读到的概念用自己的话讲出来。

回到书架，选一份资料开始吧。

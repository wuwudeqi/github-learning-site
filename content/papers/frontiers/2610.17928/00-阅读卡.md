# SwitchMem：同一条 GUI 记忆，该给文字还是截图

英文标题：Learning How to Remember: Memory Modality Selection for GUI Agents。作者：Roh, Taeyun、Park, Suhyeong、Kim, Gijin、Jang, Wonjune、Kang, Jaewoo。原始提交：2026-10-13；版本 v1；本期核验未确认正式录用，按预印本处理。

[arXiv 原始记录](https://arxiv.org/abs/2610.17928)；[原始 PDF](https://arxiv.org/pdf/2610.17928v1)。

[站内原文 PDF](2610.17928v1.pdf)。

归档许可：CC BY 4.0。已保存未修改 PDF；图的裁切另有说明。

检索到了正确的历史经验，仍要决定以什么形式交给 GUI Agent。文字简洁，但可能丢失布局关系；截图保留位置，也可能带来过期界面干扰。SwitchMem 固定检索到的记忆身份，学习在文字和图像表示之间选择，避免把“检索哪一条”和“怎么表示”两个问题混在一起。

训练时对同一状态分别加入文字与图像记忆，观察冻结执行器内部表示的变化，训练偏好探针，再把偏好变成轻量路由器的学习目标。推理时路由器只选择一种表示，再让原执行器行动。它不是每个动作都同时跑两次大模型，所以训练与部署成本应分开核算。


![SwitchMem 训练阶段比较两种记忆造成的隐藏状态变化，推理阶段仅选择一种记忆送给执行器](../../../frontiers/2026/10/2026-10-15/images/switchmem.png)

作者方法原图，CC BY 4.0。上半部分是离线构造偏好，下半部分才是推理；同一 memory ID 的限制使比较更聚焦于表示形式（[来源原图](https://arxiv.org/abs/2610.17928)；[查看原尺寸](../../../frontiers/2026/10/2026-10-15/images/switchmem.png)。）


实验冻结 Qwen3.5-9B，以 Qwen3-VL embedding 检索 top-1 经验。AITW 的步骤指标从仅图像 49.300、仅文字 48.760 提高到 51.420；LearnGUI 结果为 38.131；MobileMiniWoB 的任务成功率为 63.043。前两项的动作/步骤分数不是整条任务成功率，不能混成一个百分比排名。作者还做了匹配选择比例的随机路由对照与迁移测试。

为什么现在值得看：2026-10-13 的新预印本把记忆格式选择变成可学习模块，**新近创新；方法、基线、指标定义与消融已读，本站未复现，热度待验证**。需要访问隐藏状态，未必能直接套在封闭 API；Android 及模拟任务结果也不等于实体手机、所有新系统或 iOS 都已验证。

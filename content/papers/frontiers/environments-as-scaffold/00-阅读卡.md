# Environments as Scaffold 阅读卡

原题：Environments as Scaffold: Enriching Feedback to Bootstrap Self-Evolving Agents in Long-Horizon Tasks。[arXiv:2609.08404v1](https://arxiv.org/abs/2609.08404v1)，2026-09-08 提交，预印本。

## 为什么改环境

长任务只在终点判分，模型可能反复失败，却不知道中途哪一步出了问题。论文尝试让训练环境给出更有帮助的反馈，再观察这种训练能否迁移回标准环境。它改的是训练时的信息供给，不是评测时偷偷保留答案提示。

## 怎么给帮助

反馈丰富环境（FEE）早期偏向行动指导，后期偏向观察补充。论文采用 Qwen3-4B 和 8B，结合 GRPO、GSPO、DAPO，在 SciWorld 和 BFCL v3 多轮任务中比较。所述训练为 200 步，在第 100 步切换阶段，反馈采样概率为 0.5。

直觉是先帮助模型找到可行路线，再让它学会根据环境信息行动。实际效果仍取决于任务：提示如果替模型完成了关键判断，也可能妨碍它学会追问。

## 哪些结果不能略过

8B 与 GSPO 的 SciWorld 成绩从 53.91 到 60.94，但并非每个子任务都上升。例如 4B 与 DAPO 的 MissingParam 从 41 到 34，8B 与 GRPO 的 MissingFunc 从 52 到 48。讨论平均收益时应同时保留这些退步。

训练中每五步评测并报告峰值，复现时必须统一选点规则和评测次数。不能拿某一方法的最佳点去比较另一方法的固定最后一步，也不能把带额外反馈的训练结果直接当成开放环境的保证。

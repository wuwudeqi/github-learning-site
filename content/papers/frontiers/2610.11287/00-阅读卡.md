# REMORY: Learning Residual Memory for Context Compaction

2026-10-08 · arXiv:2610.11287v1 · 预印本，录用状态未确认。2026-10-12 阅读归档。

作者：Xia, Hanchen, Chen, Baoyou, Ge, Yutang, Deng, Naihao, Yang, Senqiao, Dong, Zilong, Yuan, Weihao, Zhu, Siyu。

## 中文摘要

把历史与摘要编码为有界软token，补足上下文压缩后仍影响后续决策的信息。

## 方法与证据

记忆网络以摘要为条件，从冻结actor特征提取连续token；先学重建，再学匹配完整历史下的后续预测，仅更新记忆网络。

SummHay同92条查询中以约5.2%的输入位置接近完整上下文联合分；AutomationBench五次运行35.5±1.3到45.3±1.0。

## 局限与复现

需要接触actor嵌入和训练记忆网络，不是纯API提示技巧；成本表不含记忆网络和工具全部开销；部分基准仅单次运行。
